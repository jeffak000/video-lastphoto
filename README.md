# 视频尾帧提取器（右键高清版）

Windows 右键菜单一键提取视频**最后一帧**，原分辨率无损 PNG 输出。
**零配置、免装 Python、内置 ffmpeg**，别的电脑解压即用。

## 特性
- 右键视频文件即可提取尾帧，原分辨率无损高清 PNG
- 内置 ffmpeg，不依赖任何运行环境（不需要 Python）
- 支持多选：选中多个视频分别提取
- 输出与视频同目录，命名为 `<原名>_尾帧.png`

## 支持的格式
`mp4` `mov` `mkv` `avi` `flv` `webm` `m4v` `wmv` `ts`

## 安装（只需一次）
1. 从 [Releases](../../releases) 下载 `video-tailframe-x.x.x.zip`
2. 解压到任意目录（如 `D:\Tools\video-tailframe`，**路径不要含中文/空格更稳妥**）
3. 双击 `install.bat`，弹出 PowerShell 窗口，提示时选择「允许一次」或「允许运行」
4. 看到「右键菜单安装完成」即成功

## 使用
在任意视频文件上 **右键 → 提取尾帧高清图**，几秒后自动打开所在文件夹，
里面多出一张 `<原名>_尾帧.png` 即完成。

## 卸载
双击 `uninstall.bat` 即可移除右键菜单。

## 常见问题
- **需要管理员吗？** 不需要，菜单写入当前用户注册表（HKCU）。
- **杀毒误报？** ffmpeg.exe 偶尔被误报，加入信任即可，不影响使用。
- **换了电脑 / 移动了目录？** 先跑 `uninstall.bat` 卸载，移动到新位置后重新跑 `install.bat`。
- **想要精确取真正的最后一帧？** 当前是快速模式（取结尾约 0.1 秒内的帧），对封面/定格足够；如需逐帧精确定位可提 issue。

## 原理
调用内置 ffmpeg：
```
ffmpeg -y -sseof -0.1 -i 视频.mp4 -frames:v 1 -q:v 2 输出.png
```
从结尾前 0.1 秒取 1 帧，保持视频原分辨率无损输出。
